# Expense Tracker Server


## About
This is a server for expense tracker application and it is built with Node.js and Express to perform CRUD operations on expense.

## Features

Create, Read, Update, and Delete (CRUD) expense APIs.

## Tech Stack
- Node.js and Express
- Typescript

## Requirements
 ```
 Express
 Node.js
 ```

## Installation
```
npm install
```

## Build
```
npm build
```
## Start the server
```
npm start
```
