# Expense Tracker Server


## About
This is a server for expense tracker application and it is built with Node.js, Express and PostgreSQL with Sequelize to perform CRUD operations on expense.

## Features
- Create, Read, Update, and Delete (CRUD) expense APIs.
- PostgreSQL database integration using Sequelize ORM
- Docker setup for easy development


## Tech Stack
- Node.js and Express
- Typescript
- PostgreSQL
- Sequelize ORM
- Docker & Docker Compose

## Requirements
 ```
 Node.js
 Express
 Docker
 ```

## To start server and database with docker
```
docker-compose up --build
```

## Installation
Install the dependencies
```
npm install
```

## Build
Compile Typescript to Javascript
```
npm build
```
## Start the server
To start server
```
npm start
```
